Calm Desk — Stress Management

A bilingual stress-care web app for people who work at a screen: the standard PSS-10 stress check, short relief exercises with before/after ratings, and a private mood log. Works offline and installs like an app.

Open live site Source code

What it does

  • PSS-10 questionnaire with scored levels and tips for your stress triggers
  • Box and 4-7-8 breathing with background sounds, 5-4-3-2-1 grounding, Bubble pop, Mind sweep and a Pomodoro timer
  • Before/after stress ratings that show which exercises help you
  • Daily check-ins, 30-day chart, CSV export and JSON backup
  • Sri Lankan helplines, offline PWA, dark mode, English and Sinhala
  • No accounts: all data stays on the device

Built with

  • Astro 5
  • Tailwind CSS 4
  • TypeScript
  • PWA
  • GitHub Pages
