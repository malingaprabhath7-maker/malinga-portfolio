Rakawarana · රැකවරණ

A bilingual CRM for insurance advisors: clients, policies, premium due dates, renewals and one-tap WhatsApp reminders.

Source code

As an insurance consultant I tracked clients in a notebook, WhatsApp chats and Excel. Premium dates were missed and policies lapsed. Rakawarana turns that notebook into a daily to-do list.

What it does

  • Today list of overdue premiums, upcoming dues, renewals, birthdays and follow-ups
  • Recording a payment moves the next due date forward and works out the commission
  • Drag-and-drop sales pipeline from lead to client
  • Ready-made Sinhala and English WhatsApp messages
  • Monthly reports against a target, with PDF and CSV export
  • Two-step login, encrypted NIC numbers, strict per-advisor data isolation and an audit log

Built with

  • Laravel 13
  • PHP 8.3
  • Tailwind CSS 4
  • Alpine.js
  • Chart.js
  • PHPUnit
  • GitHub Actions
  • Docker

My role

Solo project: product design, Laravel backend, UI, security, tests and CI.

Status

Working product with a feature test suite running on GitHub Actions.
