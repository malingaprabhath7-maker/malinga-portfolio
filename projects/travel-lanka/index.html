Travel Lanka

A bilingual Sri Lanka tour site: search and filter tours, read a day-by-day plan, see prices in USD or LKR and send a tour request on WhatsApp.

Open live site Source code

What it does

  • Search by region, interest and length; live filters for budget and days, with sorting
  • Tour pages with highlights, a day-by-day route, inclusions, best season and a map
  • Request form that totals the price for the group and opens WhatsApp or email
  • My trip planner saved on the device, with a shareable summary
  • USD/LKR switch, English and Sinhala, light and dark mode

Built with

  • Astro 5
  • Tailwind CSS 4
  • TypeScript
  • GitHub Pages

My role

Rebuilt my earlier PHP/MySQL and Bootstrap version as a fast static Astro site.

Status

Live on GitHub Pages. Portfolio demo — not a real travel agency.
