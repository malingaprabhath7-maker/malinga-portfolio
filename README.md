# Malinga Prabhath — Portfolio

My developer portfolio, in **English and Sinhala**.

**Live:** https://malingaprabhath7-maker.github.io/malinga-portfolio/ · සිංහල: https://malingaprabhath7-maker.github.io/malinga-portfolio/si/

![Portfolio](public/images/og.png)

## What's inside

- Featured case studies (Rakawarana, Viyadam Pota) with screenshots
- An index of every project with filters (web, Python & AI, mobile & IoT, university)
- A page for each project, in both languages
- Journey timeline, skills, certificates and contact
- Light and dark themes, keyboard-friendly, works on phones

## Tech

- [Astro 5](https://astro.build) — static site, zero JavaScript by default
- [Tailwind CSS 4](https://tailwindcss.com)
- Fonts: Bricolage Grotesque, IBM Plex Sans, Noto Sans/Serif Sinhala
- Deployed to GitHub Pages by GitHub Actions on every push

## Edit the content

All text lives in **`src/data/site.ts`** — projects, journey, skills, certificates and both languages. Images go in `public/images/`.

```bash
npm install
npm run dev      # http://localhost:4321/malinga-portfolio/
npm run build    # output in dist/
```
