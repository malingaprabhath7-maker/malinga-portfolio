SmartGem

ඌව පළාතේ කුඩා පරිමාණ මැණික් කර්මාන්තකරුවන්ට ගල්වල වටිනාකම දැනගන්න, හවුල්කරුවන් අතර ලාභය සාධාරණව බෙදාගන්න සහ බලපත්‍ර වලංගුව තබාගන්න උදව් කරන, offline වැඩ කරන සිංහල/ඉංග්‍රීසි mobile app එකක්.

කුඩා පරිමාණ පතල්කරුවන් බොහෝ විට වටිනාකම නොදැන අමු ගල් විකුණනවා, හවුල් ලාභ බෙදීම කඩදාසියේ තියාගන්නවා, NGJA බලපත්‍ර අලුත් කිරීමේ දින මඟ හරිනවා. පතල් බොහොමයක දුරකථන සංඥා දුර්වලයි. අධ්‍යයන ප්‍රදේශය: පස්සර, ලුණුගල, බඩල්කුඹුර සහ ඔක්කම්පිටිය.

විසඳුම

SmartGem හැම දෙයක්ම මුලින්ම phone එකේ සංකේතිත database එකක ගබඩා කරනවා — ඒ නිසා සංඥා නැති පතලක් ඇතුළෙත් වැඩ කරනවා. සම්බන්ධතාවක් ලැබුණාම Sync Manager එක දත්ත server එකට backup කරනවා. හැම තිරයක්ම එක tap එකකින් සිංහල/ඉංග්‍රීසි මාරු වෙනවා.
